# Personal Web Site (Flask recreation)

This repository contains a minimal Flask project that recreates the layout/design of the referenced personal site.

## Quick start

1. Install deps:

   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt

2. Run:

   python app.py

3. Open http://127.0.0.1:5000/

## Notes
- Replace `static/images/avatar.svg` with your real photo (or update `templates/index.html`).
- The layout and styles are a close visual recreation and intentionally minimal so you can customize easily.
